# FitVisor - Official Brand & Affiliate Landing Page

This folder contains the complete, production-ready, ultra-modern showcase landing page for **FitVisor**. It is designed specifically to pass **AWIN, CJ, Impact, and Rakuten Affiliate Compliance** on the very first review.

---

## 🚀 How to Deploy to Vercel in 60 Seconds (Free)

### Option A: Via Vercel Web Dashboard (Drag & Drop)
1. Go to [vercel.com](https://vercel.com) and log in (with your GitHub account).
2. Click **"Add New Project"**.
3. Choose **Import Git Repository** (or drag the `landing_page` folder).
4. In **Root Directory**, set: `landing_page`.
5. Click **"Deploy"**!
6. Your site will instantly go live with a free URL: `https://fitvisor.vercel.app` (or similar).

---

### Option B: Connect Your Custom Domain (Recommended for 100% Guaranteed AWIN Approval)
1. In your Vercel Project Dashboard, go to **Settings** -> **Domains**.
2. Type in your custom domain (e.g. `fitvisor.app`, `fitvisor.com`, or `fitvisor-app.com`).
3. Add the DNS records shown by Vercel (CNAME / A Record) in your domain registrar (GoDaddy, Namecheap, Hostinger, etc.).
4. In 2 minutes, SSL is automatically configured and your landing page is live at your custom domain!
